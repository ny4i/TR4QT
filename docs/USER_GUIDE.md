## Quick Start

1. **Download** the latest release for your platform (macOS, Windows, Linux)
2. **Install** following platform-specific instructions
3. **Configure** your station callsign and location in Preferences
4. **Set up** radio control (optional but recommended)
5. **Create** a new contest and start logging!

## Key Features

- **Multi-platform**: Native apps for macOS, Windows, and Linux
- **Radio control**: Hamlib integration for 200+ radio models
- **Contest support**: CQ WW, CQ WPX, ARRL Field Day, Winter Field Day, and more
- **Real-time scoring**: Automatic duplicate checking, multiplier tracking
- **Web interface**: View your log remotely from any browser
- **ADIF import/export**: Exchange logs with other logging software
- **Network capable**: UDP broadcast for multi-station viewing

## System Requirements

**macOS:**
- macOS 11 (Big Sur) or later
- 64-bit Intel or Apple Silicon

**Windows:**
- Windows 10 or later
- 64-bit x86 processor

**Linux:**
- Ubuntu 20.04 or later (or equivalent)
- Qt 6.2+ runtime libraries
